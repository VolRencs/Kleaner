Monitoring, services and cleanup in a single app.

Kleaner shows CPU, memory, disk and network usage, manages systemd services and startup entries, and cleans caches and logs. Built with Qt 6 and KDE Frameworks 6 for Arch Linux.

Installfor Arch Linux Source code

Latest release: v1.3.2  •  Qt 6.11+  •  KDE Frameworks 6.30+

Features

Nine pages: monitoring, processes, services, startup, cleanup, hosts and settings.

System monitoring

CPU (total and per core), memory, disk and network, refreshed every second.

Metric history

60-second charts for load, memory, disk and network.

Processes

Sort by columns, search by name, user or PID, terminate with SIGTERM or SIGKILL.

systemd services

Start, stop, restart and enable units over D-Bus and polkit.

Startup apps

Entries from ~/.config/autostart and /etc/xdg/autostart: toggle and edit.

System cleaner

Trash, caches, /tmp, /var/log, systemd journal, pacman cache and orphan packages.

/etc/hosts

Entry table with IPv4/IPv6 validation and an atomic write through KAuth.

Languages and appearance

Russian and Ukrainian interfaces, runtime language switching, dark theme.

PAGES

Application pages

Screenshots from a regular session: the interface and its controls.

Overview

Three ring gauges (CPU, memory, root volume) and a spec table: host, distribution, kernel, CPU model, user and uptime. Below — mounted volumes with used space.

  • Ring gauges: CPU, memory, root volume
  • Spec table: host, distribution, kernel, CPU, user, uptime
  • Volumes: mount point, filesystem, used/total

Resources

Five overview charts with 60 seconds of history plus a per-core breakdown. Data accumulates while the app is running and is not reset when you switch pages.

  • CPU: usage and 1/5/15-minute load average
  • Memory and swap
  • Disk: read and write; network: receive and transmit

Processes

Process table with click-to-sort columns and search by name, user or PID. The list refreshes every 2 seconds while the scroll position and selected row stay put.

  • Columns: name, PID, user, CPU, memory, RSS, state, command
  • Terminate (SIGTERM) and force-kill (SIGKILL)
  • Refresh by button or automatically every 2 seconds

Services

systemd units with description, state and an autostart switch. Start, stop and restart go over D-Bus; polkit asks for a password when needed.

  • Start, stop and restart units
  • Enable and disable autostart
  • Sort by name, state or autostart

Startup apps

Entries from ~/.config/autostart and /etc/xdg/autostart. Disabling a system entry copies it into your user directory.

  • Enable and disable entries
  • Add, edit and remove .desktop files
  • Fields: name, command, comment, icon

System cleaner

Seven categories with size calculation. Tick the items you need, see the total size and remove them; selections persist across restarts.

  • Trash, application caches, crash reports
  • System logs: rotation and full journal archive cleanup
  • pacman cache and orphan package removal

Hosts

A table of /etc/hosts entries: address and hostnames. IPv4/IPv6 and names are validated before saving; the write goes through KAuth.

  • View, add, edit and delete entries
  • IPv4/IPv6 and hostname validation
  • Save through KAuth with confirmation

Settings

Startup page, close behavior (ask, minimize to tray, quit), tray icon and interface language. Settings are stored in ~/.config/kleanerrc.

  • Application startup page
  • Close behavior and tray icon
  • Interface language: system, Russian, Ukrainian and more

IMPLEMENTATION

Qt 6, KDE Frameworks 6 and Wayland.

The interface is Qt Quick Controls with its own dark theme. Services and processes use the system D-Bus, while cleanup and /etc/hosts go through the KAuth helper with polkit confirmation.

  • One window and one process, no embedded terminal
  • systemd over D-Bus, file operations through KAuth
  • Arch Linux: build with PKGBUILD or CMake

Technologies: Qt 6KDE Frameworks 6QMLKAuthsystemdWayland
